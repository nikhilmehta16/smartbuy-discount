# SmartBuy Discount Price

Chrome extension that shows the price after your expected discount
next to every flight price on `offers.reward360.in` (HDFC SmartBuy).

Example: `₹15,069` → `₹15,069 [-15% ₹12,809]`

## Install
1. Open `chrome://extensions` and turn on **Developer mode**.
2. Click **Load unpacked** and pick this folder.
3. Click the extension icon to change the discount % (default 15).
